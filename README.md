## Workforce Analysis

The dashboard provides insights into:

- Employee distribution by gender
- Employee type distribution
- Full-Time vs Part-Time workforce
- Average Full-Time Equivalent (FTE)
- Department-level workforce information

### Employee Type

The workforce is categorized into:

- Permanent
- Temporary
- Fixed Term

### Employment Status

The dashboard compares:

- Full-Time Employees
- Part-Time Employees

---

## Compensation Analysis

Salary information is analyzed across departments and gender to understand the distribution of total compensation within the organization.

The dashboard includes:

- Total salary
- Average salary
- Minimum salary
- Maximum salary
- Department-wise salary distribution
- Gender-wise salary distribution
